# Olá, eu sou o Lucas 👋

Desenvolvedor mobile e fullstack, estudante de Engenharia de Computação na UTFPR (Apucarana-PR, conclusão prevista para 12/2026). Trabalho com **React Native, TypeScript e Node.js** e tenho interesse crescente em **engenharia de IA**: agentes, LLMs locais e avaliação de modelos.

## Em foco agora

- **TCC:** orquestração de tarefas com agentes LLM locais sobre Kubernetes (protótipo em Flask + Ollama + Kind). O código está em repositório privado até a submissão do artigo; disponível sob solicitação.
- **Projetos de IA:** classificação de imagens com PyTorch e avaliação de LLMs contra rótulos humanos.
- **Dia a dia:** aplicativos móveis em produção, com monitoramento de erros (Sentry/GlitchTip) e integração contínua.
